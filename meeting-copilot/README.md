# Meeting Copilot

This project is an AI-powered meeting assistant.

## Structure

- `backend/`: Node.js server for handling client connections and Python communication.
- `frontend/`: React-based user interface.
- `ml/`: Python scripts for AI functionalities (transcription, vision, LLM).
- `config/`: Configuration files for the application.
